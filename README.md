## 📖 Overview

**Pixel Avatar Creator** is a modern browser-based avatar customization application that allows users to create unique pixel-art characters with an intuitive interface.

Customize every aspect of your avatar—from hairstyle and facial features to clothing, accessories, and skin tone—then save your creation directly as an image.

Built entirely with **HTML**, **CSS**, and **Vanilla JavaScript**, the project demonstrates modular JavaScript architecture, dynamic rendering, and responsive UI design.

---

## ✨ Features

- 🎨 Live pixel avatar preview
- 💇 Multiple hairstyles
- 👀 Different eye styles
- 👓 Glasses customization
- 🧔 Beard selection
- 👕 Clothing options
- 🎨 Hair color palette
- 🏽 Multiple skin tones
- 🔀 Random avatar generator
- 🔍 Zoom In / Zoom Out

# 🎮 How It Works

1. Choose a category from the sidebar.
2. Select an avatar part.
3. Pick your preferred colors.
4. Watch the avatar update instantly.
5. Zoom if needed.
6. Download your avatar as a PNG.
